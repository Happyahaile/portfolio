Values & Mission

Values

  • Clarity over cleverness: I prefer simple, readable solutions that teammates can maintain.
  • Small, steady progress: ship in increments, learn from feedback, improve the next commit.
  • Reliability: tests and monitoring matter more than flashy features.
  • Respect & communication: listen first, ask good questions, write things down.
  • Privacy & accessibility: build with real users in mind, not just ideal ones.

Mission

Build useful, honest software that reduces everyday friction. I focus on practical tools, clear interfaces, and code that others can extend. If a feature helps someone finish their task a little faster or with less confusion, it’s a good day.
